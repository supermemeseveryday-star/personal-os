## 第一步

仪表盘上有一张 **快速开始** 卡片，共三步：

1. **填写你的名字**：打开设置页。名字会显示在问候语和侧边栏中。
2. **创建第一个项目**：项目用来归类相关任务，例如「网站改版」。
3. **添加第一个任务**：下一件具体要做的事。

完成一步打勾一步，也可以随时点 **×** 关闭卡片。

首次打开时，界面语言跟随浏览器。可以在顶部的 **中 / EN** 或设置页里切换。

## 仪表盘

| 区域 | 内容 |
|---|---|
| 数据卡片 | 今日任务数、今日已完成、进行中、今日完成率 |
| 当前专注 | 正在做的任务，或下一个该开始的任务 |
| 今日 / 今日日程 | 今天的任务和提醒，按时间排序 |
| 进行中的项目 | 最多四个进行中项目的进度 |
| 提醒 | 接下来的三条提醒 |
| 技能 / 时间投入 | 技能水平，以及本周的专注、学习、会议时长 |

仪表盘分成几页。可以用底部的 **上一页 / 下一页**、圆点、键盘 `←` `→` 切换，手机上可以左右滑动。

## 任务

**添加任务**
- 在任务列表顶部的 **快速添加** 框中输入，按 **回车** 即可。任务默认今天截止，光标会留在框里，方便连续添加。
- 需要填写更多信息时，点 **添加任务**、按 `N`，或点顶部的 **+**。

**任务字段：** 名称、描述、所属项目、状态（待办 / 进行中 / 已完成 / 已取消）、优先级（低 → 紧急）、截止日期与时间、预计时长（分钟）、标签（用逗号分隔）。

**管理任务**
- 勾选复选框完成任务，取消勾选可重新打开。
- 点任务名称可以编辑或删除。
- 逾期任务的截止时间显示为红色。
- 截止时间的显示：今天显示「10:00」，明天显示「明天 9:00」，其余显示日期。

## 专注计时

1. 在仪表盘点 **开始专注**，或点任意任务行右侧的 ▶。
2. 计时显示在仪表盘上。切换到其他页面时，顶部会出现一个小计时器，点它即可回到仪表盘。
3. **暂停 / 继续**、**结束**（保存这次记录）、**完成**（保存记录并把任务标记为已完成）。

每次专注都会保存为时间记录，出现在日历、项目数据、每周复盘和数据分析中。

## 项目与里程碑

- **项目** 页面以卡片显示每个项目的进度（已完成任务的比例）、任务数，以及下一个里程碑或截止日期。
- 点卡片进入项目详情：数据、里程碑、任务、备注和操作。
- 项目详情中有专属的快速添加框，可以直接给这个项目添加任务。
- **里程碑** 是带日期的关键节点，达成后打勾。
- **归档** 会把项目从进行中列表隐藏，但不会删除；**取消归档** 可恢复。
- **删除** 会删除项目及其里程碑，项目中的任务会保留但取消关联。删除后可以立即撤销。

## 日历

- 可切换 **月 / 周 / 日** 视图。用箭头前后切换，点 **今天** 回到今天。
- 颜色：蓝色 = 任务，橙色 = 提醒，紫色 = 里程碑，绿色 = 专注 / 学习 / 会议时间。
- 点任意条目即可编辑；点日期进入当天视图。
- 鼠标移到某一天会出现 **+**，点它即可添加当天截止的任务。

## 提醒

- 用来记录不属于任务的事情：缴费、打电话、预约等。
- **重复** 可选：不重复、每天、每周、每月。
- 勾选重复提醒时，它会自动顺延到下一次，并提示下次时间；不重复的提醒会被标记为已完成。
- 逾期提醒显示为红色。点垃圾桶图标删除（可撤销）。

## 技能、学习与目标

- **技能**：添加技能，设置当前水平和目标水平（0–100），按分类分组。点技能可以更新水平，变化会记录在历史中。
- **学习**：记录学习或练习，包括主题、关联技能、时长、日期、来源和备注，会计入复盘中的学习时间。
- **目标**：长期成果，包含目标日期和进度，可关联项目和技能。点目标卡片即可编辑。

## 每周复盘与数据分析

- **每周复盘**（本周一到今天）：新建任务数、完成任务数、完成率、专注时长、进展最多的项目、逾期任务，以及接下来要做的事。
- **数据分析**：最近 7 天的完成任务数和专注时长、各项目的专注时间、技能水平。可以用 **记录时间** 手动添加会议或其他时间。

## 设置、备份与重置

- **显示名称** 和 **语言**。
- **导出数据**：把所有记录下载为 JSON 文件，文件名为 `personal-os-年-月-日.json`。
- **导入数据**：用备份文件替换当前工作区，导入后可以立即撤销。
- **清空所有数据**：清空工作区，之后可以立即撤销；提示消失后无法恢复。
- **安装为应用** 以及快捷键列表。

## 快捷键

| 按键 | 作用 |
|---|---|
| `⌘K` / `Ctrl K` 或 `/` | 搜索记录、快速创建、跳转页面 |
| `N` | 新建任务 |
| `⌘Enter` / `Ctrl Enter` | 保存当前表单 |
| `←` `→` | 上一页 / 下一页内容 |
| `Esc` | 关闭弹窗或手机菜单 |

## 安装为应用

| 设备 | 方法 |
|---|---|
| Windows、macOS、Android 上的 Chrome / Edge | 点顶部或设置页的 **安装应用**，或地址栏的安装图标 |
| iPhone / iPad | Safari → 分享 → **添加到主屏幕** |
| Mac 上的 Safari | 文件 → **添加到程序坞** |

安装后会以独立窗口打开、可离线使用。长按（手机）或右键（电脑）图标，可以直接「新建任务」「日历」「记录学习」。

## 常见问题

**别人能看到我的数据吗？** 不能。记录只存在你设备上的浏览器里，网站部署者也看不到。

**我在手机上打开网站，任务都不见了？** 每台设备、每个浏览器的工作区是独立的。请在一台设备上导出，再到另一台设备导入。

**iPhone 添加到主屏幕后，之前的数据不见了？** Safari 和主屏幕 App 的存储是分开的。请先在 Safari 中导出，再在主屏幕 App 中导入。

**很久没打开，数据会丢吗？** Safari 可能会清除大约一周没访问的网站数据，添加到主屏幕可以避免。无论用什么设备，定期导出备份都是最保险的做法。

**不小心删错了怎么办？** 点屏幕底部提示条中的 **撤销**，提示会保留几秒钟。
