## First steps

The dashboard shows a **Get started** card with three steps:

1. **Add your name**: opens Settings. Your name appears in the greeting and the sidebar.
2. **Create your first project**: a project groups related tasks, for example "Website redesign".
3. **Add your first task**: the next concrete thing to do.

Each step gets a tick when done. Close the card with **×** at any time.

The language follows your browser on first visit. Switch between **中** and **EN** in the header or in Settings.

## Dashboard

| Area | What it shows |
|---|---|
| Metrics | Tasks due today, completed today, in progress, and today's completion rate |
| Current focus | The task you are working on, or the next one to start |
| Today / Today's schedule | Today's tasks and reminders in time order |
| Active projects | Progress of up to four active projects |
| Reminders | The next three open reminders |
| Skills / Time invested | Your skill levels and this week's focus, learning and meeting time |

The dashboard has several pages. Use **Previous** / **Next** at the bottom, the dots, the `←` `→` keys, or swipe on a phone.

## Tasks

**Add a task**
- Type in the **Quick add** box at the top of the task list and press **Enter**. The task is due today and the cursor stays in the box so you can add the next one straight away.
- For more detail, click **Add task**, press `N`, or use the **+** in the header.

**Task fields:** title, description, project, status (Todo / In progress / Done / Cancelled), priority (Low → Urgent), due date and time, estimate in minutes, tags (comma separated).

**Work with tasks**
- Tick the checkbox to complete a task; untick to reopen it.
- Click a task's title to edit or delete it.
- Overdue tasks show their due time in red.
- Due dates read "10:00" for today, "Tomorrow 9:00" for tomorrow, otherwise the date.

## Focus timer

1. Press **Start focus** on the dashboard, or the ▶ button on any task row.
2. The timer runs on the dashboard. On other pages a small timer appears in the header; click it to come back.
3. **Pause / Resume**, **End** (saves the session) or **Complete** (saves the session and marks the task done).

Every session is stored as a time entry and appears in the calendar, project metrics, weekly review and analytics.

## Projects and milestones

- **Projects** shows a card per project with progress (share of completed tasks), task count and the next milestone or deadline.
- Click a card to open the project page: metrics, milestones, tasks, notes, and actions.
- Add tasks directly in the project with its own quick-add box.
- **Milestones** are key checkpoints with a date. Tick them as you reach them.
- **Archive** hides a project from the active list without deleting it; **Unarchive** brings it back.
- **Delete** removes the project and its milestones. Its tasks are kept but unlinked. You can undo right after.

## Calendar

- Switch between **Month**, **Week** and **Day**. Use the arrows to move and **Today** to jump back.
- Colours: blue = task, orange = reminder, purple = milestone, green = focus, learning or meeting time.
- Click any item to edit it. Click a date to open that day.
- Hover a day and click **+** to add a task due that day.

## Reminders

- Add reminders for things that are not tasks: bills, calls, appointments.
- **Repeat** can be None, Daily, Weekly or Monthly.
- Ticking a repeating reminder moves it to the next date and tells you when that is. A one-off reminder is marked done.
- Overdue reminders are shown in red. Delete with the bin icon (undo available).

## Skills, learning and goals

- **Skills**: add skills with a current level and a target level (0–100), grouped by category. Click a skill to update its level; changes are kept in its history.
- **Learning**: log study or practice sessions with topic, skill, duration, date, source and notes. Sessions count towards learning time in reviews.
- **Goals**: long-term outcomes with a target date and progress, linked to projects and skills. Click a goal card to edit it.

## Weekly review and analytics

- **Weekly review** (Monday to today): tasks created and completed, completion rate, focus time, the project that moved most, overdue tasks and what is coming next.
- **Analytics**: completed tasks and focus time for the last 7 days, focus time per project and skill levels. Use **Log time** to add meetings or other time manually.

## Settings, backup and reset

- **Display name** and **Language**.
- **Export data** downloads all your records as a JSON file named `personal-os-YYYY-MM-DD.json`.
- **Import data** replaces the current workspace with a backup file. You can undo it straight after.
- **Clear all data** empties the workspace. You can undo it straight after; once the message disappears it is permanent.
- **Install as an app** and the list of keyboard shortcuts.

## Keyboard shortcuts

| Keys | Action |
|---|---|
| `⌘K` / `Ctrl K` or `/` | Search records, create items, jump to a page |
| `N` | New task |
| `⌘Enter` / `Ctrl Enter` | Save the open form |
| `←` `→` | Previous / next content page |
| `Esc` | Close a dialog or the mobile menu |

## Install as an app

| Device | How |
|---|---|
| Chrome / Edge on Windows, macOS, Android | **Install app** in the header or Settings, or the install icon in the address bar |
| iPhone / iPad | Safari → Share → **Add to Home Screen** |
| Safari on macOS | File → **Add to Dock** |

Once installed it opens in its own window and works offline. Long-press (phone) or right-click (desktop) the icon for **New task**, **Calendar** and **Log learning** shortcuts.

## FAQ

**Can other people see my data?** No. Records live only in your browser on your device. The site owner cannot see them.

**I opened the site on my phone and my tasks are missing.** Each device and browser has its own workspace. Export on one device and import on the other.

**On iPhone, my data disappeared after I added the app to the Home Screen.** Safari and the home-screen app keep separate storage. Export from Safari, then import in the installed app.

**Will my data be lost if I don't open the site for a while?** Safari may clear data for websites not visited for about a week. Installing to the Home Screen avoids this. On any device, a regular export is the safest backup.

**I deleted something by mistake.** Click **Undo** in the message at the bottom of the screen. It stays for a few seconds.
